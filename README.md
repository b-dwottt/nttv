
# 📺 NTTV IPTV Playlist

173 channels — M3U playlist for NTTV players.

---

## 📱 How to Use

1. **Copy this raw URL:**
   ```
   https://raw.githubusercontent.com/b-dwottt/nttv/main/finalnttv.m3u
   ```

2. **Paste it into any IPTV player:**
   - VLC → Media → Open Network Stream → paste URL
   - TiviMate → Add Playlist → URL
   - IPTV Smarters → Load Playlist → URL
   - OTT Navigator → Add Source → M3U URL

---

## 👥 Who Can Use It

- Anyone with an **IPTV player** app
- Works on: **Windows, macOS, Android, iOS, Smart TV**
- No account or login required

---

## ⚠️ Limitations

- **Nepal Telecom (NT) IPTV only** — This playlist is extracted from Nepal Telecom's IPTV service. It will **only work if you are a Nepal Telecom IPTV subscriber**.
- **Local network only** — Streams are UDP multicast (`239.100.1.x`). Must be connected to the same network as the ONT/router.
- **No EPG** — This is a raw playlist. Channel names only, no program guide.
- **Wi-Fi only** — Multicast-to-unicast conversion required for Wi-Fi. Wired Ethernet works directly.
